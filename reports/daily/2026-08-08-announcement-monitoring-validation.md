# 公告事件监控验证

## 结论

公告事件监控的采集、不可变存档、标准化和透明分类链路已建立，并用真实同花顺问财响应验证。

## 验证样本

- 查询：A股最近七日股份回购公告
- 数据源：同花顺问财
- 原始响应：1 个不可变快照
- 标准化批次：`5ef25c69d98dc28af30b`
- 公告记录：2
- 事件类型：`share_repurchase`
- 标准化器版本：`1.1.0`
- 分类规则版本：`1.1.0`
- 事件文件 SHA-256：`ad5569a1a7deb3c98e38e796f2088e1bbc40412a60dee36c3911c8397ecea19d`

真实响应中的证券信息位于 `stock_infos`，代码为不含交易所后缀的六位来源代码。系统保留 `source_security_code` 和证券名称，但不猜测标准证券代码；后续应与证券主表确定性关联。

## 审计边界

- API 密钥和授权头不进入 raw 快照。
- 网关响应在 `payload` 内不删减、不映射。
- 公告发布时间同时作为当前 `available_from`，支持后续时点分析。
- 每条标准化事件保留完整原始条目、原始记录 ID 和快照路径。
- 关键词分类只组织事件类型，不判断利好或利空。
- 本次没有生成投资建议、交易信号或自动操作。
